# Data

Drop the raw apartment files here.

- `plans/`      → floor-plan files exported from the Autodesk Viewer (`.dwfx`, and a `.pdf` export if you have one)
- `pricelists/` → the project's price list / apartment table (`.xlsx`, `.csv`, or `.pdf`)

Name files clearly, e.g. `plans/apartment-12-floor3.dwfx`.
These are source inputs for parsing — nothing here is generated.
